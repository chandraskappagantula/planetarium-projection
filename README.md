# Planetarium-Projection
Mathematically projects a provided image onto the inside of a spherical dome by distorting the image so that when it is projected onto said spherical dome, it will look the way it's supposed to; personal project useful for home planetarium demonstrations. 

Two long-term features will be planned: 
1. Projecting any image onto the inside of a spherical dome with inputted dimensions
2. Animating a series of images to replicate night sky movement
